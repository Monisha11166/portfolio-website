About me

I'm a web design student learning to turn a plain page into something clear to read and pleasant to use. My favourite moment is when a layout finally clicks: the boxes line up, and the page still works on a phone.

This year I have been building small projects with HTML, CSS, JavaScript and Bootstrap, from a shared shopping cart to an online store landing page. I test every page at phone and desktop widths before I call it done.

How I build a page

  1. Plan the sections and sketch the layout.
  2. Write the HTML structure and content.
  3. Style it with CSS, starting with the phone layout.
  4. Test on desktop and mobile, then fix what breaks.
